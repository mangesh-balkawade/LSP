# Linux System Programming (LSP) in C

This repository contains a collection of **Linux System Programming (LSP)** programs written in **C**, aimed at understanding low-level operating system concepts through hands-on examples.

## 📌 About the Repository

The programs in this repository demonstrate how Linux internally handles files, processes, memory, and inter-process communication using **system calls** and **POSIX APIs**.

This repository is useful for:

* Students learning Operating Systems
* Beginners in Linux System Programming
* Interview preparation
* Revision of core OS concepts

## 🛠️ Topics Covered

* File handling (`open`, `read`, `write`, `close`)
* File descriptors and permissions
* Process management (`fork`, `exec`, `wait`)
* Signals
* Inter-Process Communication (IPC)

  * Pipes
  * FIFO
* System calls and error handling
* Low-level C programming concepts

## 🧪 How to Compile and Run

Use **GCC** to compile the programs:

```bash
gcc program_name.c -o program_name
./program_name
```

Make sure you are using a **Linux-based system**.
